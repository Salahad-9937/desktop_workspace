# 4.1. Модель данных состояния и однонаправленный поток {#sec-01-state-model-and-flow}

## 4.1.1. Неизменяемое дерево состояния (Immutable State Tree)

Состояние всего рабочего пространства описывается единым иерархическим неизменяемым деревом данных. Любая модификация координат, размеров или состава вкладок порождает новый экземпляр снимка состояния без прямой мутации существующих полей по месту:

```text
WorkspaceState (Снимок состояния пространства):
  ├── screenSize          : Размер видового экрана (W, H)
  ├── focusedWindowId     : Идентификатор сфокусированного окна
  ├── pendingSnapZone     : Активная зона прилипания при перетаскивании
  ├── snapPreviewRect     : Геометрический прямоугольник оверлея предпросмотра
  ├── config              : Глобальные параметры (высота дока, пороги магнита)
  └── windows             : Упорядоченный список окон [WindowState_0, ...]
        ├── id            : Уникальный идентификатор окна
        ├── x, y, width, h: Физические координаты и габариты
        ├── activeTabIndex: Индекс текущего отображаемого представления
        ├── isPinnedOnTop : Флаг постоянного удержания поверх остальных
        ├── isMinimized   : Флаг скрытия в док-панель
        ├── isMaximized   : Флаг полноэкранного развертывания
        ├── restoreRect   : Сохраненная геометрия для отката из тайлинга
        └── tabs          : Список вложенных представлений [WorkspaceTab_0, ...]
```

Преимущества неизменяемого состояния:

* **Абсолютная детерминированность:** Исключаются состояния гонки при одновременных событиях мыши и программных вызовах.

* **Легковесный расчет различий (Diffing):** Графический слой обновляет только те окна, ссылки на объекты которых изменились в новом снимке.

* **Поддержка истории (Undo/Redo):** Состояние может сохраняться в стековый массив снимков для реализации отката ошибочных действий пользователя.

## 4.1.2. Диспетчеризация команд и однонаправленный поток (Unidirectional Flow)

Управление рабочим пространством строго подчинено принципу однонаправленного потока данных:

```text
+-------------------------------------------------------------+
|                     ИСТОЧНИКИ СОБЫТИЙ                       |
|   (Жесты указателя, Клик по кнопке, API хоста, Таймер)      |
+-------------------------------------------------------------+
                              |
                              v (Вызов команды мутации)
+-------------------------------------------------------------+
|             ДИСПЕТЧЕР КОМАНД (WORKSPACE CONTROLLER)         |
|   - moveWindow(id, delta)                                   |
|   - resizeWindow(id, handle, delta)                         |
|   - tileWindow(id, mode)                                    |
|   - selectTab(id, index)                                    |
|   - detachTab(id, index, position)                          |
+-------------------------------------------------------------+
                              |
                              v (Формирование нового снимка)
+-------------------------------------------------------------+
|             НОВОЕ НЕИЗМЕНЯЕМОЕ СОСТОЯНИЕ (STATE)            |
+-------------------------------------------------------------+
                              |
                              v (Реактивное уведомление)
+-------------------------------------------------------------+
|               ПРЕЗЕНТАЦИОННЫЙ СЛОЙ (ВИДЖЕТЫ)                |
|   - Оконный холст перерисовывает изменившиеся рамки         |
+-------------------------------------------------------------+
```

Визуальные компоненты лишены права напрямую менять поля моделей. Они лишь посылают сигналы контроллеру, который валидирует геометрические ограничения, производит математические расчеты и публикует обновленное состояние.
