# 4.3. Система именованных профилей (Workspace Profiles) {#sec-03-workspace-profiles}

## 4.3.1. Концепция прикладных перспектив

Профессиональные среды требуют различных конфигураций интерфейса в зависимости от текущей задачи оператора. Система именованных профилей (Workspace Profiles / Perspectives) позволяет организовать переключение между комплексными раскладками в один клик.

Профиль представляет собой именованный снимок структуры рабочего пространства:

```text
WorkspaceProfile:
  - id          : Уникальный строковый ключ профиля
  - name        : Отображаемое название (например, "Сбор данных", "Анализ")
  - isFactory   : Признак базового системного профиля (запрет перезаписи)
  - layout      : Список размещений окон и вкладок
```

Каждая запись размещения фиксирует:

* Набор вкладок в окне и индекс активной вкладки.
* Пропорциональные (нормализованные от 0.0 до 1.0) координаты и размеры окна относительно видового экрана. Использование относительных долей гарантирует корректную раскладку на мониторах с различным разрешением.
* Флаги тайлинга, минимизации и закрепления.

---

## 4.3.2. Мгновенное переключение рабочих сред

Переключение с профиля $A$ на профиль $B$ выполняется мгновенно и бесшовно:

1. Оконный менеджер сопоставляет состав представлений в текущем и целевом профилях.
2. Для представлений, присутствующих в обоих профилях, сохраняются существующие экземпляры и внутреннее состояние (курсоры, скролл, введенные данные). Они лишь плавно анимируют свои координаты и размеры к новым целевым позициям.
3. Представления, отсутствующие в целевом профиле, переводятся в пассивный режим каталога.
4. Новые представления, требуемые целевым профилем, инстанцируются в соответствующих контейнерах.

Пользовательские манипуляции с профилями:

* **Сохранение («Сохранить профиль как…»):** Текущее пространственное расположение окон фиксируется под новым именем и добавляется в список доступных сред.
* **Сброс к исходному:** Если пользователь хаотично переместил окна в заводском профиле, команда сброса возвращает сетку к идеальному эталонному состоянию разработчика.
