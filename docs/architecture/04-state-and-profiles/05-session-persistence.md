# 4.5. Прозрачная персистентность сессии (Session Persistence) {#sec-05-session-persistence}

## 4.5.1. Непрерывная фиксация пользовательской сессии

Пользователь не должен совершать специальных действий (нажимать кнопки сохранения, выбирать пункты меню) для того, чтобы приложение запомнило удобное для него расположение окон. Оконный менеджер реализует принцип **прозрачной персистентности сессии (Zero-Click Session Persistence)**:

```text
[Интерактивное действие: ресайз, перетаскивание, смена вкладки]
                             |
                             v
             [Диспетчер фиксирует новое состояние]
                             |
                             v
           [Таймер дебаунса сессии (например, 500 мс)]
                             |
                             v
        [Вызов абстрактного адаптера сохранения сессии]
                             |
                             v
       [Запись снимка в постоянное хранилище хоста]
```

Особенности дебаунса:
Частые высокочастотные события (например, непрерывное перетаскивание окна указателем на 60 кадрах в секунду) не вызывают операций записи в постоянное хранилище на каждом пикселе. Запись дебаунсится и фиксирует снимок через короткую паузу покоя после завершения жеста.

---

## 4.5.2. Контракт восстановления рабочей среды

Архитектура предоставляет абстрактный сервисный контракт персистентности:

1. **Экспорт состояния:** Контроллер умеет преобразовывать текущий снимок `WorkspaceState` в нейтральный структурированный словарь данных, очищенный от прикладных объектов и контекстов отображения.
2. **Импорт состояния:** Контроллер принимает ранее сохраненный словарь данных, валидирует соответствие идентификаторов вкладок зарегистрированному каталогу представлений и восстанавливает точные координаты, размеры и порядок слоев.
3. **Безопасная деградация:** Если в сохраненном состоянии присутствуют вкладки, которые были удалены из новой версии прикладной программы, менеджер безопасно пропускает отсутствующие элементы, не допуская сбоя загрузки остальных окон.
