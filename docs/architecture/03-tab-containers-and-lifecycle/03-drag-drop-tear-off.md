# 3.3. Протокол Drag-and-Drop: отрыв вкладки (Tear-off) {#sec-03-drag-drop-tear-off}

## 3.3.1. Детекция жеста отрыва и фазы переноса

Отрыв вкладки в отдельное плавающее окно (Tear-off) обеспечивает естественную реорганизацию рабочего пространства без обращения к диалоговым меню. Процесс разделяется на три последовательные стадии:

```text
[Захват чипа вкладки указателем]
               |
               v
[Фаза 1: Смещение внутри полосы заголовка]
               |
               +---> Указатель покинул пределы заголовка?
               |         |
               |         +--[НЕТ]---> Локальная сортировка вкладок в окне
               |         |
               |         +--[ДА]----> [Фаза 2: Активация режима отрыва]
               |                      - Чип переходит в режим полупрозрачного фантома
               |                      - Холст активирует глобальный трекинг координат
               v
[Фаза 3: Отпускание кнопки указателя над холстом]
               |
               +---> Точка сброса находится над заголовком другого окна?
                         |
                         +--[ДА]----> Передача вкладки в целевое окно (Слияние)
                         |
                         +--[НЕТ]---> Создание нового окна в точке сброса
```

1. **Фаза локального упорядочивания:** Пока курсор перемещается в пределах высоты полосы заголовка окна-источника, вкладка меняет свой порядковый номер среди соседних табов.
2. **Фаза пространственного отрыва:** При выходе курсора за пределы полосы заголовка на расстояние более $D_{tear\_threshold}$ (по умолчанию 20 пикселей) активируется глобальный режим перетаскивания. Под курсором отображается полупрозрачный силуэт вкладки с заголовком и пиктограммой.
3. **Фаза материализации нового окна:** При сбросе вкладки на свободное пространство холста оконный менеджер атомарно удаляет вкладку из окна-источника и инстанцирует новое окно с базовыми размерами, центрируя заголовок нового окна относительно координат сброса.

---

## 3.3.2. Обработка окна с единственной вкладкой

Особый граничный случай представляет перетаскивание вкладки в окне, где она является **единственной**:

* **Запрет деструкции окна-источника во время жеста:** Если в окне осталась одна вкладка, ее отрыв не должен мгновенно уничтожать текущее окно, порождая визуальные артефакты.
* **Трансформация в перемещение окна:** При попытке вытягивания единственной вкладки система плавно переключает операцию с отрыва вкладки на **перемещение всего оконного фрейма**. Контейнер следует за указателем как цельное окно.
* **Исключение окон-призраков:** Недопустима ситуация, при которой вкладка отрывается, а на ее прежнем месте остается пустой фрейм без содержимого. Окно-источник ликвидируется синхронно с успешной материализацией вкладки на новой позиции.
