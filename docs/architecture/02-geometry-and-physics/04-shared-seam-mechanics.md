# 2.4. Механика синхронного изменения общего шва (Shared Seam) {#sec-04-shared-seam-mechanics}

## 2.4.1. Детекция состыкованных оконных групп

В классических плавающих оконных менеджерах изменение размера окна затрагивает строго один контейнер, порождая зазоры или наложения. В архитектуре Desktop Workspace реализован алгоритм **общего шва (Shared Seam)**: если два или более окон состыкованы ребрами «стык в стык», изменение границы одного окна синхронно перестраивает геометрию смежных окон.

```text
      Окно A (Левое)                 Окно B (Правое)
+--------------------------+  +--------------------------+
|                          |  |                          |
|                          |  |                          |
|                          |->|<- ОБЩИЙ ШОВ              |
|                          |  | (Зазор <= Epsilon)       |
|                          |  |                          |
+--------------------------+  +--------------------------+
  Ширина: w_A + delta           Ширина: w_B - delta
```

Условия признания ребра общим швом между окном $A$ и окном $B$:

1. **Координатная непрерывность по оси стыка:**
   * Для вертикального шва: $|(x_A + w_A) - x_B| \le \epsilon_{seam}$ (правое ребро $A$ соприкасается с левым ребром $B$).
   * Для горизонтального шва: $|(y_A + h_A) - y_B| \le \epsilon_{seam}$ (нижнее ребро $A$ соприкасается с верхним ребром $B$).
   Где допуск стыка $\epsilon_{seam} \approx 6.0$ пикселей.
   
2. **Проекционное перекрытие по смежной оси:** 

   Наличие общего сегмента длины ребра:
   $$\operatorname{Overlap}(A, B) > L_{seam\_min}$$

## 2.4.2. Алгоритм пропорционального изменения линейных размеров

При захвате и перетаскивании общего вертикального шва на дельту $\Delta x$ алгоритм производит парную модификацию геометрии:

1. **Корректировка ведущего окна (Window A):**
   $$w_A' = w_A + \Delta x$$
2. **Корректировка ведомого окна (Window B):**
   $$x_B' = x_B + \Delta x, \quad w_B' = w_B - \Delta x$$

Позиция левого края ведущего окна $x_A$ и правого края ведомого окна $x_B + w_B$ остаются абсолютно неподвижными. В результате исключаются щели и наложения, а суммарная ширина состыкованной группы сохраняется постоянной:

$$w_A' + w_B' = (w_A + \Delta x) + (w_B - \Delta x) = w_A + w_B = \text{Const}$$

Аналогичная система уравнений применяется к горизонтальным швам при вариации по оси $Y$.

## 2.4.3. Соблюдение предельных размерных ограничений

Любая деформация шва жестко подчинена индивидуальным ограничениям каждого окна:

$$\mathcal{C}_i = \langle W_{min, i}, \ W_{max, i}, \ H_{min, i}, \ H_{max, i} \rangle$$

Перед применением дельты $\Delta x$ вычисляется допустимый диапазон свободного хода шва $[\Delta x_{min}, \ \Delta x_{max}]$:

$$\Delta x_{max} = \min\left( W_{max, A} - w_A, \quad w_B - W_{min, B} \right)$$

$$\Delta x_{min} = \max\left( W_{min, A} - w_A, \quad w_B - W_{max, B} \right)$$

Результирующее перемещение ограничивается диапазоном:

$$\Delta x_{effective} = \operatorname{clamp}(\Delta x, \ \Delta x_{min}, \ \Delta x_{max})$$

Если одно из окон достигает своего предельного минимального размера $W_{min}$, дальнейшее смещение шва в этом направлении полностью блокируется, предотвращая схлопывание контейнера.
