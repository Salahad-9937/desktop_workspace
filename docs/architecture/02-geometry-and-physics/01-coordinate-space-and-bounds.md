# 2.1. Координатное пространство и границы {#sec-01-coordinate-space-and-bounds}

## 2.1.1. Двумерная метрика и доступная рабочая область

Пространство рабочего холста задается прямоугольной областью в евклидовой плоскости $\mathbb{R}^2$. Начало координат $(0, 0)$ расположено в верхнем левом углу доступного экрана:

$$\Omega = \{ (x, y) \in \mathbb{R}^2 \mid 0 \le x \le W_{canvas}, \ 0 \le y \le H_{canvas} \}$$

Где $W_{canvas}$ и $H_{canvas}$ — полная ширина и высота физического видового экрана.

В случае присутствия в рабочем пространстве постоянных интерфейсных полос (например, нижней панели быстрого доступа высотой $H_{dock}$), полезная рабочая область холста $\Omega_{work}$ вычисляется вычетом зарезервированных зон:

$$\Omega_{work} = [0, \ W_{avail}] \times [0, \ H_{avail}]$$

$$W_{avail} = W_{canvas}, \quad H_{avail} = \max(0.0, \ H_{canvas} - H_{dock})$$

Геометрическое состояние каждого $i$-го окна задается вектором четырех параметров $B_i = \langle x_i, y_i, w_i, h_i \rangle$, определяющих координаты левого верхнего угла, ширину и высоту.

## 2.1.2. Инвариант видимости и зажим координат (Bounds Clamping)

При интерактивном перетаскивании окна вектором смещения указателя $\vec{\Delta} = (\Delta x, \Delta y)$ недопустима ситуация, при которой полоса заголовка окна полностью покидает пределы видимой рабочей области $\Omega_{work}$, делая возврат окна невозможным.

Для обеспечения инварианта гарантированной видимости применяется алгоритм пространственного зажима координат верхнего левого угла $(x, y)$:

```text
+----------------------- W_avail -----------------------+
| (0,0)                                                 |
|   +-------------------+                               |
|   | Заголовок окна    | <- Заголовок гарантированно    |
|   +-------------------+    удерживается внутри        |
|   | Тело контейнера   |    видимой области            |
|   +-------------------+                               |
|                                                       |
|                                                       |
| (0, H_avail)                                          |
+-------------------------------------------------------+
```

Математическая формулировка зажима координат для окна с шириной $w$ и высотой $h$:

$$x_{clamped} = \operatorname{clamp}\left(x_{target}, \ 0.0, \ \max(0.0, \ W_{avail} - W_{min\_visible})\right)$$

$$y_{clamped} = \operatorname{clamp}\left(y_{target}, \ 0.0, \ \max(0.0, \ H_{avail} - H_{header})\right)$$

Где:

* $H_{header}$ — физическая высота интерактивной полосы заголовка окна.

* $W_{min\_visible}$ — гарантированный минимальный горизонтальный сегмент заголовка, обязанный оставаться внутри экрана для возможности обратного захвата указателем.

## 2.1.3. Адаптация при ресайзе внешнего видового экрана

При изменении габаритов окна базового приложения от $\Omega_{old} = (W_{old}, H_{old})$ к $\Omega_{new} = (W_{new}, H_{new})$ все плавающие и тайловые окна подвергаются детерминированной трансформации:

1. **Окна в развернутом или тайловом состоянии:** Пересчитываются в новые координаты согласно пропорциональным долям занимаемых зон (например, правая половина принимает $x = W_{new} / 2$, $w = W_{new} / 2$, $h = H_{new}$).
2. **Свободные плавающие окна:**
   * Если окно полностью укладывается в новые габариты, его координаты остаются неизменными.
   * Если правый или нижний край окна пересекает новую границу ($x_i + w_i > W_{new}$ или $y_i + h_i > H_{new}$), координата смещается влево/вверх на величину превышения:

   $$x_i' = \min(x_i, \ \max(0.0, \ W_{new} - w_i))$$

   $$y_i' = \min(y_i, \ \max(0.0, \ H_{new} - h_i))$$

   * Если ширина или высота окна превышают новые размеры экрана ($w_i > W_{new}$ или $h_i > H_{new}$), линейный размер усекается до текущего максимума с соблюдением порога $W_{min}$.
