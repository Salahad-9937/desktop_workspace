# 2.3. Тайлинг и геометрия зон предпросмотра {#sec-03-tiling-and-preview-zones}

## 2.3.1. Краевые триггерные зоны холста

Быстрый тайлинг (Quick Tiling) позволяет упорядочивать окна в регулярные структуры без ручной подгонки габаритов. Активация тайлинга происходит при поднесении курсора манипулятора к периметру рабочей области $\Omega_{work}$ на расстояние меньше порогового $D_{edge}$ (по умолчанию 48 пикселей).

Разметка триггерных зон видового экрана:

```text
(0,0)-------------------------------------------------(W,0)
| Верхняя левая 1/4 |    Развертывание во весь экран   | Верхняя правая 1/4 |
|-------------------+----------------------------------+--------------------|
|                   |                                  |                    |
| Левая половина    |         Центральная зона         | Правая половина    |
| экрана            |        свободного плавания       | экрана             |
|                   |                                  |                    |
|-------------------+----------------------------------+--------------------|
| Нижняя левая 1/4  |    Развертывание во весь экран   | Нижняя правая 1/4  |
(0,H)-------------------------------------------------(W,H)
```

Математический селектор зоны тайлинга по координате курсора $(P_x, P_y)$:

$$Zone(P_x, P_y) = \begin{cases}
\text{Maximize}, & \text{если } P_y \le D_{edge} \text{ при } D_{edge} < P_x < W - D_{edge} \\
\text{TopLeft}, & \text{если } P_x \le D_{edge} \text{ и } P_y \le H \cdot 0.35 \\
\text{BottomLeft}, & \text{если } P_x \le D_{edge} \text{ и } P_y \ge H \cdot 0.65 \\
\text{LeftHalf}, & \text{если } P_x \le D_{edge} \text{ при } H \cdot 0.35 < P_y < H \cdot 0.65 \\
\text{TopRight}, & \text{если } P_x \ge W - D_{edge} \text{ и } P_y \le H \cdot 0.35 \\
\text{BottomRight}, & \text{если } P_x \ge W - D_{edge} \text{ и } P_y \ge H \cdot 0.65 \\
\text{RightHalf}, & \text{если } P_x \ge W - D_{edge} \text{ при } H \cdot 0.35 < P_y < H \cdot 0.65 \\
\text{None}, & \text{в остальных случаях}
\end{cases}$$

## 2.3.2. Расчет геометрии контура предпросмотра

В фазе интерактивного предпросмотра функция отображения вычисляет целевой прямоугольник $R_{preview} = \langle x, y, w, h \rangle$ для отрисовки полупрозрачного индикатора:

* **Левая половина (LeftHalf):** $\langle 0, \ 0, \ W_{avail} / 2, \ H_{avail} \rangle$.
* **Правая половина (RightHalf):** $\langle W_{avail} / 2, \ 0, \ W_{avail} / 2, \ H_{avail} \rangle$.
* **Верхняя левая четверть (TopLeft):** $\langle 0, \ 0, \ W_{avail} / 2, \ H_{avail} / 2 \rangle$.
* **Верхняя правая четверть (TopRight):** $\langle W_{avail} / 2, \ 0, \ W_{avail} / 2, \ H_{avail} / 2 \rangle$.
* **Нижняя левая четверть (BottomLeft):** $\langle 0, \ H_{avail} / 2, \ W_{avail} / 2, \ H_{avail} / 2 \rangle$.
* **Нижняя правая четверть (BottomRight):** $\langle W_{avail} / 2, \ H_{avail} / 2, \ W_{avail} / 2, \ H_{avail} / 2 \rangle$.
* **Полный экран (Maximize):** $\langle 0, \ 0, \ W_{avail}, \ H_{avail} \rangle$.

## 2.3.3. Сохранение и восстановление плавающих координат

Для исключения безвозвратной утраты пользовательского макета при тайлинге каждый контейнер хранит опциональный вектор предшествующей свободной геометрии $B_{restore} = \langle x_{rest}, y_{rest}, w_{rest}, h_{rest} \rangle$.

1. **Фиксация перед тайлингом:** Если окно находилось в свободном плавающем режиме, в момент применения тайлинга текущие координаты копируются в стек восстановления:
   $$B_{restore} \leftarrow B_{current}$$
2. **Откат при выходе из тайлинга:** При захвате заголовка тайлового окна указателем и смещении его за пределы пороговой зоны тайлинг сбрасывается. Окно мгновенно возвращает исходные линейные размеры $(w_{rest}, h_{rest})$, а координаты центра заголовка центрируются относительно текущей позиции курсора.
