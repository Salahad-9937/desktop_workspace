# 2.2. Математика магнитного притягивания (Magnet Snapping) {#sec-02-magnet-snapping-math}

## 2.2.1. Векторный расчет притяжения к границам экрана

Магнитное притягивание (Magnet Snapping) устраняет необходимость ручного попиксельного позиционирования окон у краев видового экрана. При перемещении окна рассчитывается расстояние от его четырех граней до соответствующих границ рабочей области $\Omega_{work}$.

Пусть $T_{magnet}$ — радиус порогового захвата магнитного поля (по умолчанию 10 пикселей). Координаты окна $B = \langle x, y, w, h \rangle$ корректируются оператором проекции:

$$x_{snapped} = \begin{cases} 
0.0, & \text{если } |x| < T_{magnet} \\
W_{avail} - w, & \text{если } |(x + w) - W_{avail}| < T_{magnet} \\
x, & \text{в остальных случаях}
\end{cases}$$

$$y_{snapped} = \begin{cases} 
0.0, & \text{если } |y| < T_{magnet} \\
H_{avail} - h, & \text{если } |(y + h) - H_{avail}| < T_{magnet} \\
y, & \text{в остальных случаях}
\end{cases}$$

Если окно попадает в радиус действия одновременно по горизонтали и по вертикали, происходит примагничивание в соответствующий угол экрана.

## 2.2.2. Межоконное притяжение граней (Snap-to-Edge)

Помимо границ холста, система рассчитывает взаимное притяжение граней между перемещаемым окном $A = \langle x_A, y_A, w_A, h_A \rangle$ и неподвижными окнами множества $\mathcal{W}_{passive}$.

```text
       Окно B (неподвижное)
       +--------------------+ 
       |                    |
       |                    | x_B + w_B
-------+--------------------+==========
       : <- Зазор < T_magnet:
       +--------------------+
       |                    | x_A
       |                    |
       Окно A (перемещаемое)
```

Два ребра притягиваются друг к другу только при наличии проекционного перекрытия по перпендикулярной оси:

1. **Горизонтальное примагничивание (стыковка по вертикальному ребру):**

   Ребра $x_A$ (левое) или $x_A + w_A$ (правое) сравниваются с ребрами $x_B$ и $x_B + w_B$ окна $B$ при выполнении условия вертикального перекрытия:

   $$\operatorname{Overlap}_Y(A, B) = \max\left(0.0, \ \min(y_A + h_A, \ y_B + h_B) - \max(y_A, \ y_B)\right) > L_{overlap\_min}$$

   При наличии перекрытия:
   * Стыковка встык справа: если $|x_A - (x_B + w_B)| < T_{magnet}$, то $x_A \leftarrow x_B + w_B$.
   * Стыковка встык слева: если $|(x_A + w_A) - x_B| < T_{magnet}$, то $x_A \leftarrow x_B - w_A$.
   * Выравнивание по левому краю: если $|x_A - x_B| < T_{magnet}$, то $x_A \leftarrow x_B$.
   * Выравнивание по правому краю: если $|(x_A + w_A) - (x_B + w_B)| < T_{magnet}$, то $x_A \leftarrow x_B + w_B - w_A$.

2. **Вертикальное примагничивание (стыковка по горизонтальному ребру):**

   Рассчитывается аналогично при выполнении условия горизонтального перекрытия $\operatorname{Overlap}_X(A, B) > L_{overlap\_min}$.

## 2.2.3. Фильтрация коллизий и радиус захвата

Для сохранения вычислительной производительности и устранения пространственного дребезга окон вводятся следующие ограничения:

* **Исключение невидимых объектов:** Из массива проверки $\mathcal{W}_{passive}$ безусловно исключаются минимизированные окна, окна в процессе закрытия и само перемещаемое окно $A$.
* **Приоритет границы холста:** Если ребро окна одновременно попадает в радиус притяжения границы холста и ребра соседнего окна, абсолютный приоритет имеет граница холста.
* **Порог отрыва:** При дальнейшем движении манипулятора за пределы порога $T_{magnet}$ окно плавно отлипает от ребра без скачков скорости курсора.
