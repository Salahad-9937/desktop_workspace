# 5.2. Анатомия оконного фрейма и заголовка {#sec-02-window-frame-and-titlebar}

## 5.2.1. Несущий фрейм окна

Оконный фрейм формирует физические границы контейнера, отделяющие прикладной контент от остального пространства холста:

* **Рамка фокуса:** Внешний контур толщиной 1.0–1.5 пикселя. В активном состоянии окрашивается в акцентный цвет темы, при потере фокуса переходит в нейтральный приглушенный оттенок.
* **Тени пространственной глубины:** Контейнер проецирует направленную тень. Для активного сфокусированного окна радиус размытия и оптическая плотность тени увеличиваются, создавая визуальное ощущение приподнятости над плоскостью холста.
* **Скругления углов:** Фиксированный радиус скругления внешних углов рамки (типовой диапазон 6.0–8.0 пикселей), согласованный с общей стилистикой приложения.

## 5.2.2. Заголовок окна и распределение интерактивных зон

Полоса заголовка располагается вдоль верхнего края фрейма и имеет фиксированную высоту (типовое значение 32–36 пикселей). Заголовок решает три задачи: отображение вкладок, предоставление зоны захвата для перемещения и размещение органов управления.

```text
+-------------------------------------------------------------------------------+
| [Таб 1] [Таб 2*] [+] |      СВОБОДНАЯ ЗОНА ПЕРЕМЕЩЕНИЯ     | [*] [T] [_] [^] [X] |
+-------------------------------------------------------------------------------+
   ^                      ^                                     ^
   |                      |                                     |
Чипы вкладок        Захват перемещения                     Базовые кнопки:
(Drag / Click)      (Drag / Double-click)                  - Пин [ * ]
                                                           - Меню тайлинга [ T ]
                                                           - Свернуть [ _ ]
                                                           - Развернуть [ ^ ]
                                                           - Закрыть [ X ]
```

Функциональное разделение зон заголовка:

1. **Зона чипов вкладок:** Содержит горизонтальный список вкладок. Каждый чип отображает пиктограмму, заголовок и индивидуальную кнопку закрытия. Чип поддерживает клик для выбора активного представления и захват для локального упорядочивания или пространственного отрыва.

2. **Свободная зона перемещения:** Занимает все свободное пространство между вкладками и кнопками управления. Поддерживает жест перетаскивания всего окна и двойной клик для переключения режима развертывания.

3. **Блок базовых органов управления:** Компактная панель иконочных кнопок фиксированной ширины.

---

## 5.2.3. Точка расширения прикладных действий

В профессиональных средах в заголовок окна требуется выносить контекстные прикладные действия, специфичные для отображаемой панели (например, выбор масштаба времени, переключатель режима рендеринга, кнопка фиксации снимка).

Заголовок предоставляет специализированный интерфейсный слот расширения:

```text
+-------------------------------------------------------------------------------+
| [Вкладки...] | [Зона драга] | [ПРИКЛАДНЫЕ ДЕЙСТВИЯ] | [Стандартные кнопки...] |
+-------------------------------------------------------------------------------+
                                          ^
                                          |
                              Кастомные органы управления:
                              - Кнопка паузы потока
                              - Переключатель фильтра
                              - Выпадающий список масштаба
```

Слот прикладных действий размещается непосредственно перед стандартным блоком кнопок управления окном. Прикладное приложение передает в этот слот произвольный набор управляющих элементов, которые получают контекст текущего окна и активной вкладки.
