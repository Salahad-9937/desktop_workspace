# 5.4. Панель быстрого доступа и переключения окон (Workspace Dock) {#sec-04-workspace-dock}

## 5.4.1. Архитектурная автономия док-панели

Док-панель (Workspace Dock) проектируется как независимый модульный компонент переключения оконных контекстов. Архитектура поддерживает два режима развертывания панели:

1. **Встроенный режим:** Панель закрепляется вдоль нижней (или верхней) границы рабочего холста, автоматически резервируя пространство высотой $H_{dock}$ и уменьшая полезную площадь $\Omega_{work}$.
2. **Внешний (автономный) режим:** Панель исключается из состава холста и монтируется хостовым приложением в произвольное место своего интерфейса (например, в системную панель статуса, боковое навигационное меню или заголовок окна приложения). В этом режиме холст занимает 100% выделенного ему пространства.

---

## 5.4.2. Анатомия элементов док-панели

Док-панель организует пространство по горизонтали, разделяясь на функциональные блоки:

```text
+-----------------------------------------------------------------------------+
| [ВЕДУЩИЙ СЛОТ] | [ЧИП ОКНА 1] [ЧИП ОКНА 2*] [ЧИП 3 (свернут)] | [ВЕДОМЫЙ СЛОТ] |
+-----------------------------------------------------------------------------+
```

Элементы панели:

* **Ведущий слот (Leading Slot):** Опциональный контейнер в левой части дока. Используется для размещения кнопки вызова Каталога представлений или селектора рабочих профилей.

* **Лента оконных чипов:** Горизонтальный прокручиваемый список чипов всех открытых на холсте окон.
  * Чип отображает пиктограмму активной вкладки окна, ее заголовок и количество дополнительных вкладок в контейнере.
  * Активное окно, находящееся в фокусе, подсвечивается акцентной рамкой.
  * Свернутое окно отображается в полупрозрачном затемненном состоянии.
  * Клик по чипу разворачивает свернутое окно или передает фокус окну на холсте с переносом на вершину Z-Index. Повторный клик по уже сфокусированному окну сворачивает его.
  
* **Ведомый слот (Trailing Slot):** Опциональный контейнер в правой части дока для размещения прикладных индикаторов хоста (сетевой статус, монитор ресурсов, переключатели режимов).

## 5.4.3. Всплывающая карточка предпросмотра (Hover Preview)

При удержании курсора мыши над оконным чипом док-панели дольше 250 миллисекунд над панелью всплывает легковесная карточка предпросмотра:

```text
        +-----------------------------------+
        |       ПРЕДПРОСМОТР КОНТЕЙНЕРА     |
        |  +-----------------------------+  |
        |  |                             |  |
        |  |  Схематичная пиктограмма    |  |
        |  |  или миниатюра содержимого  |  |
        |  |                             |  |
        |  +-----------------------------+  |
        |  Заголовок: Инспектор данных      |
        |  Вкладок в окне: 3                |
        +-----------------------------------+
                          |
                   [ ЧИП ОКНА 2* ]
```

Карточка предпросмотра предоставляет быструю визуальную идентификацию содержимого свернутого или перекрытого окна без необходимости активации и изменения текущего Z-Index.
