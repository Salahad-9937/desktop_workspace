# 5.1. Композиция рабочего холста (Workspace Canvas) {#sec-01-canvas-composition}

## 5.1.1. Многослойная структура холста

Рабочий холст представляет собой многослойный визуальный стек, упорядоченный вдоль виртуальной пространственной оси глубины:

```text
Визуальный стек холста (снизу вверх):

Слой 4: ОВЕРЛЕЙНЫЙ СЛОЙ (OVERLAY LAYER)
        - Контур предпросмотра тайлинга (SnapPreviewBox)
        - Перетаскиваемый фантом вкладки при операции Tear-off
------------------------------------------------------------------
Слой 3: ПЛОСКОСТЬ ЗАКРЕПЛЕННЫХ ОКОН (PINNED TIER)
        - Оконные фреймы с флагом Always-on-Top
------------------------------------------------------------------
Слой 2: ПЛОСКОСТЬ СТАНДАРТНЫХ ОКОН (STANDARD TIER)
        - Оконные фреймы в порядке локального Z-Index
------------------------------------------------------------------
Слой 1: СЛОЙ НАПРАВЛЯЮЩИХ И ИНДИКАТОРОВ (GUIDES LAYER)
        - Краевые маркеры зон прилипания
------------------------------------------------------------------
Слой 0: БАЗОВЫЙ ФОНОВЫЙ СЛОЙ (BACKGROUND LAYER)
        - Фоновая поверхность холста с координатной сеткой
```

Назначение слоев:

* **Фоновый слой (Слой 0):** Обеспечивает визуальную опору пространства, отображая нейтральную координатную сетку с шагом, кратным базовой сетке макета.

* **Слой направляющих (Слой 1):** Отрисовывает пассивные контуры краевых зон прилипания (половины, четверти, развертывание) с прозрачностью для событий указателя (`hitTest = false`).

* **Плоскости окон (Слои 2 и 3):** Содержат физические оконные фреймы. Разделение на стандартный и закрепленный ярусы исключает перекрытие важных контрольных панелей фоновыми окнами.

* **Оверлейный слой (Слой 4):** Располагается на самом верхнем уровне и служит для отображения высокодинамичных полупрозрачных индикаторов, существующих только во время активного жеста пользователя.

## 5.1.2. Изоляция графических областей (Render Invalidation Separation)

Для сохранения частоты обновления интерфейса (60/120 кадров в секунду) при непрерывном перемещении или ресайзе окон презентационный слой реализует изоляцию областей перерисовки:

1. **Изолированный композитный слой фрейма:** Каждый оконный контейнер выделяется в автономную графическую границу композитинга.
2. **Локализация инвалидации:** Изменение экранных координат $(x, y)$ перемещаемого окна трансформирует только его собственный графический слой. Соседние неподвижные окна, фоновый холст и прикладные представления не получают команд на перерисовку растрового представления.
3. **Пассивность неактивных вкладок:** Скрытые вкладки внутри контейнера полностью отключаются от графического конвейера отрисовки, исключая паразитное потребление ресурсов графического процессора.
