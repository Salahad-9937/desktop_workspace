# 5.3. Механика границ изменения размера {#sec-03-resize-boundaries}

## 5.3.1. Восьмизонный интерактивный периметр захвата

Изменение линейных размеров контейнера осуществляется через восемь сенсорных зон, распределенных по периметру фрейма:

```text
(NW) [====== СЕВЕРНОЕ РЕБРО (N) ======] (NE)
 [|]                                     [|]
 [|]                                     [|]
 ЗАПАД                                 ВОСТОК
 (W)                                     (E)
 [|]                                     [|]
 [|]                                     [|]
(SW) [====== ЮЖНОЕ РЕБРО (S) ==========] (SE)
```

Геометрия зон захвата:

* **Линейные ребра (Север, Юг, Запад, Восток):** Полосы шириной $D_{edge\_handle} \approx 6.0$ пикселей, расположенные вдоль соответствующих сторон окна между угловыми секторами.

* **Угловые секторы (NW, NE, SW, SE):** Квадратные или прямоугольные области размером $D_{corner\_handle} \approx 14.0 \times 14.0$ пикселей в вершинах окна. Обеспечивают одновременное изменение ширины и высоты.

* **Угловая засечка захвата:** Юго-восточный угол контейнера дополнительно маркируется визуальной диагональной засечкой, подсказывающей основную точку растяжения окна.

## 5.3.2. Бесконфликтный проброс событий указателя

Зоны изменения размера физически накладываются на внешние границы оконного фрейма. Для предотвращения блокировки интерактивных элементов внутри окна (скролл-бары у правого края, текстовые поля у границ) применяется селективный алгоритм диспетчеризации событий:

1. **Внешнее перекрытие:** Полоса ручки ресайза на 50% выносится за пределы внешнего контура окна и на 50% внутрь.
2. **Приоритет границы при захвате:** Если указатель находится строго в пределах полосы захвата, жест нажатия безусловно перехватывается оконным менеджером для масштабирования.
3. **Прозрачность для кликов:** Одиночные клики без смещения, пришедшиеся на внутреннюю часть полосы ручки, прозрачно пробрасываются в нижележащие прикладные виджеты.

## 5.3.3. Динамическая подмена системных курсоров

При наведении указателя на сенсорные зоны периметра оконный менеджер динамически запрашивает у базовой платформы соответствующий системный курсор:

* **Северная (N) и Южная (S) зоны:**
  - Вектор деформации: Вертикальный.
  - Назначаемый курсор: Двунаправленная вертикальная стрелка (Resize Up/Down).
* **Западная (W) и Восточная (E) зоны:**
  - Вектор деформации: Горизонтальный.
  - Назначаемый курсор: Двунаправленная горизонтальная стрелка (Resize Left/Right).
* **Северо-западная (NW) и Юго-восточная (SE) зоны:**
  - Вектор деформации: Главная диагональ.
  - Назначаемый курсор: Диагональная стрелка (Resize Top-Left / Bottom-Right).
* **Северо-восточная (NE) и Юго-западная (SW) зоны:**
  - Вектор деформации: Побочная диагональ.
  - Назначаемый курсор: Диагональная стрелка (Resize Top-Right / Bottom-Left).

Сброс системного курсора к стандартной стрелке происходит немедленно при выходе указателя за пределы сенсорной зоны.
