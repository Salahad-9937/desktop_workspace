# Desktop Workspace

Модульный оконный менеджер холста для настольных приложений на Flutter.

Библиотека предназначена для построения гибких многопанельных интерфейсов: аналитических терминалов, инженерных дашбордов, сред мониторинга и редакторов данных.

---

## Возможности

* **Управление окнами:** свободное перемещение, расчет Z-индекса, закрепление поверх всех и гарантированное удержание заголовков в границах экрана.
* **Геометрическое ядро:** магнитное прилипание к краям холста и смежным окнам, быстрый тайлинг с визуальным предпросмотром и синхронное масштабирование состыкованных окон по общему шву.
* **Вкладки и контейнеры:** группировка панелей во вкладки, Drag-and-Drop отрыв в отдельное окно (Tear-off) и слияние (Merge), удержание состояния неактивных виджетов в памяти без потери данных и скролла.
* **Профили и сессии:** сохранение и быстрое переключение именованных рабочих пространств (перспектив), декларативные сетки и прозрачное автосохранение сессии.
* **Стилизация и интеграция:** изоляция слоев рендеринга для плавной отрисовки, семантическая система дизайн-токенов темы, модульная док-панель и чистый контракт фабрики содержимого.
